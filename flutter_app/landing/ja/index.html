3ステップでインストール

  1. ダウンロードお使いのパソコン用のダウンロードボタンを押します。
  2. インストールMac：.dmgを開き、Pricing AIを「アプリケーション」にドラッグ。Windows：インストーラーを実行。
  3. 起動Pricing AIを起動します。最初のAI作業でAIエンジンとモデルを一度だけダウンロードします（0.5〜5 GB）。その後はパソコン上でAIが動きます。

最初の価格から、最初の予約まで。

政府調達の案件分析

アプリ内で台湾の政府電子調達システムを検索：落札金額、競合企業とその落札実績を、ローカルAIの要約やGoogle AIモードと合わせて確認できます。

サービス価格の計算

時給・固定費・目標の利益を入力すると、サービスごとの本当の原価と、利益率に届く価格を計算します。14通貨の税と丸めに対応。

予約サイトの作成

英語・繁體中文・日本語・Português・Españolのひな形から始めて、画面で編集。よくある質問や流れ図、ハイテクなダーク表示も。ZIPで書き出すか、Firebaseに公開。

Googleフォームとカレンダーで予約

Apps Script 1つで、予約フォームと「予定あり」だけ公開のカレンダーを作成。予約は自動でカレンダーに入り、サイトに空き状況が表示されます。

Mac・WindowsのローカルAI

デスクトップ版は自分のGPUでオープンモデルを動かし、チャットでサイトを作成、部分的な書き直し、バナー画像の生成までこなします。クラウドのAIにデータは送りません。

デスクトップアプリとブラウザ版

ブラウザ版（Chromeが「インストール」を勧めるショートカットを含む）はデスクトップアプリではなく、AIがありません。

使い方

  1. 価格を決めるコストと目標の利益を入力して、サービスごとの料金表を作ります。
  2. サイトを作る料金表をひな形に追加するか、チャットでお店を説明します。
  3. 予約をつなぐGoogleフォームのリンクを貼るか、スクリプト1つでフォームとカレンダーを作ります。
  4. 公開するZIPを任意のサーバーに置くか、デスクトップ版からFirebaseへ公開します。

よくある質問

デスクトップアプリとブラウザ版の違いは？

デスクトップアプリには、ローカルAI、政府調達の案件分析、競合企業の調査、ワンクリック公開があります。ブラウザ版は無料でインストール不要ですが、AIはありません。

Chromeが Pricing AI の「インストール」を勧めてきます。これはアプリですか？

いいえ。Chromeがインストールするのはブラウザ版のショートカット（Pricing AI Web）です。AIや案件分析を使うには、このページからMacまたはWindowsのアプリをダウンロードしてください。

Pricing AI はオープンソースですか？

はい。コードは Apache License 2.0 で GitHub に公開しており、インストーラーは Releases に、すべての第三者ライブラリのライセンスもそこに掲載しています。

無料ですか？

Web版の価格計算・サイト作成・ZIP書き出しは無料です。MacとWindows版では、ローカルAIとワンクリック公開が加わります。

AIにデータがクラウドへ送られますか？

いいえ。デスクトップ版のAIモデルは自分のパソコン上で動きます。Web版にAIはなく、データはブラウザ内に留まります。

プログラミングは必要ですか？

不要です。画面やチャットでページを編集でき、予約フォームはGoogleフォームでつなぎます。

対応言語は？

アプリとサイトのひな形は、英語・繁体字中国語・日本語・ブラジルのポルトガル語・スペイン語です。

予約はどう受け取りますか？

訪問者があなたのサイトからGoogleフォームを送信します。スクリプトが予約をGoogleカレンダーに追加し、Googleフォームでメール通知もオンにできます。
