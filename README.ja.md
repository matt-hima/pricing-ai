# Pricing AI

Pricing AI は、小さなサービス業とソフトウェア開発会社が自信を持って価格を決められるようにするアプリです。サービスごとの本当の原価を計算し、予約サイトを作り、ソフトウェア開発を見積もり、台湾の政府調達で類似案件がいくらで落札されたかを調べられます。AI は自分のパソコン上で動作し、データがクラウドの AI に送られることはありません。

- 公式サイト：https://pricingai.minervaelectronics.com/ja/
- macOS 版のダウンロード：https://github.com/matt-hima/pricing-ai/releases/latest
- ブラウザ版（AI なし・インストール不要）：https://pricingai.minervaelectronics.com/app/?lang=ja

## 機能

アプリには 4 つのタブがあります。

### 1. サービス価格

美容室・クリニック・飲食店・教室・レンタルスペース向け。

- 時給、月々の固定費、予約できる時間数、目標の利益、税率、端数処理を入力します。
- サービスごとに所要時間（分）と材料費を入力すると、本当の原価、利益率に届く価格、利益が表示されます。
- 1 時間あたりの間接費、損益分岐となる時間数、計画どおりの月間利益をまとめて表示します。
- 14 通貨とそれぞれの一般的な税・端数処理に対応。CSV で書き出すか、ワンクリックで料金表を予約サイトに追加できます。
- デスクトップ版：AI が業種に合ったサービスを提案し、「相場を調べる」で同業の一般的な料金をウェブ検索して料金表にまとめます（検索結果に実際に出てきた価格だけを使います）。

### 2. サイト作成

- 英語・繁体字中国語・日本語・ポルトガル語・スペイン語のひな形から始めて、画面上で編集できます。
- サービスと料金、よくある質問、流れ図、ハイテクなダーク表示を追加できます。
- Google フォームで予約を受け付け：Apps Script 1 つで予約フォームと「予定あり」を表示するカレンダーを作り、予約は自動でカレンダーの予定になります。
- ZIP で書き出して、任意のサーバーに置けます。
- デスクトップ版：チャットでお店を説明すると AI がページを書き、部分的な書き直しやバナー画像の生成も行います。Firebase へワンクリックで公開できます。

### 3. 開発の見積もり（ソフトウェア開発）

- 自社情報、人月単価と税率、顧客、見積もり条件を入力します。
- プロジェクトの種類、プラットフォーム（Web、iOS、Android など）、デザインのレベル、最大 17 の機能モジュールを選び、それぞれに自由な説明を書けます。
- 合計金額の幅（上限には 1.2〜1.5 倍のリスクバッファを含む）、工程ごとの人月、スケジュール、保守費用の目安が出ます。
- PDF 見積書をリアルタイムでプレビュー、ダウンロード、印刷、または営業担当に送信できます。
- デスクトップ版：ローカル AI が各モジュールをサブタスクに分けて工数を見積もります。価格は常にアプリが単価から計算し、AI が決めることはありません。
- 「過去の案件」：台湾の政府電子調達システムで類似の落札案件を開き、見積もりの横に相場と競争状況を要約します（下記参照）。

### 4. 案件分析（台湾の政府調達）

デスクトップ版の機能です。本物の政府電子調達システム（web.pcc.gov.tw）がアプリ内のブラウザで開き、ご自身で閲覧します。アプリは開いたページだけを読み取ります。

- サイトの検索ルールに沿ったキーワード拡張：検索語は一続きの文字列として照合される（空白は無視）ため、網站／網頁／官網 などの言い方を別々に検索して結合します。
- 落札金額：件数、中央値、中間 50%、平均、範囲と分布、よく発注する機関、入札方式。
- 自分の見積もりの位置：類似案件の何 % より高いか、低価格帯・一般的・高価格帯のどれか。
- 競争状況：落札公告をいくつか開くと、入札者数、予算に対する落札率、落札企業がわかります。
- 競合になりそうな企業：開いた公告のすべての入札企業を表示し、各社の過去 12 か月の落札・入札記録（落札件数、入札件数、落札率、一般的な落札金額、取引の多い機関）を調べられます。
- Google AI モードをアプリ内のブラウザで開き、企業や市場の公開情報をご自身で確認できます。
- 案件を CSV で書き出せます。
- 公式オープンデータ：政府電子調達システムの落札データセット（100万元以上・約2か月遅れ）をダウンロードし、認証チェックなしで数年分をまとめて分析：落札金額、よく落札する企業、機関、落札方式。出典：行政院公共工程委員会 政府電子調達システム オープンデータ（政府資料開放授權條款－第1版）。

## ダウンロードとインストール（macOS）

1. [最新リリース](https://github.com/matt-hima/pricing-ai/releases/latest)から `PricingAI-mac.dmg` をダウンロードします。
2. .dmg を開き、**Pricing AI** を「**アプリケーション**」にドラッグします。
3. Pricing AI を起動します。このビルドはまだ Apple Developer ID で署名されていないため、初回は macOS が「開発元を確認できません」と表示する場合があります。「**システム設定 → プライバシーとセキュリティ**」で「**このまま開く**」を押してください（初回のみ）。
4. 最初の AI 作業で AI エンジンとモデルを一度だけダウンロードします（0.5〜5 GB）。その後はパソコン上で AI が動きます。

Windows 版は近日公開予定です。

### 動作環境

| | |
|---|---|
| macOS | 10.15 以降。Apple シリコン推奨（画像生成には Apple シリコンが必要） |

| ディスク | AI エンジンとモデル用に約 1〜6 GB の空き |

## プライバシー

- デスクトップ版：AI モデルは llama.cpp でパソコン上で動作します（Mac は Metal、Windows は Vulkan）。見積もり、価格、サイトはパソコンに保存されます。
- ブラウザ版：AI はなく、データはブラウザに保存されます。
- ネットワークを使う場面：AI エンジンとモデルのダウンロード（GitHub、Hugging Face）、案件分析を使うときにアプリ内ブラウザで開く調達サイトと Google、「相場を調べる」では検索語が Bing に送られます。
- 見積もりや価格は計画用の目安であり、助言や拘束力のある見積もりではありません。

## ソースからのビルド

[Flutter](https://flutter.dev)（Dart 3.12 以降）が必要です。macOS 版のビルドには Xcode、Windows 版のビルドには Windows 上の Visual Studio が必要です。

```bash
cd flutter_app
flutter pub get
flutter test                      # ユニット・ウィジェットテスト
flutter run -d macos              # ローカル AI 付きのデスクトップ版
flutter build macos --release     # Pricing AI.app
flutter build web --base-href /app/
```

実際の Mac アプリの統合テスト（本物の調達サイトとローカル AI を使用）：

```bash
cd flutter_app
LIVE_ENGINE_STORAGE=/path/to/pricing-ai caffeinate -d -i flutter test integration_test/case_analysis_app_test.dart -d macos
```

サイトとツール：

| コマンド | 内容 |
|---|---|
| `tool/deploy.sh` | チェック、テスト、`/app/` 向けの Web 版ビルド、サイトの組み立て、Firebase Hosting への公開（`--no-deploy` はビルドのみ） |
| `tool/build_site.sh` | `build/site` を組み立てる：公式サイトは `/`、Web 版は `/app/` |
| `python3 tool/gen_landing.py` | ダウンロード中心の公式サイトを 5 言語で生成（インストーラーのリンクは `HOSTED_URLS`） |
| `python3 tool/gen_notices.py` | 第三者ライセンスの一覧と全文を再生成 |
| `python3 tool/check_i18n.py` | 5 言語の文字列がそろっているか確認 |
